# Source provenance

The FPGA wrapper, OCL bridge, testbench, synthesis script, implementation script,
and constraints were imported from the retained Coral NPU F2 build sources.
The baseline uses Coral commit `382b5c12030ad8eb74ab8deafb2529301faeab16`.

The original generated `RvvCoreMiniAxi.sv` has SHA-256
`2a19a5c7ea2ece404b0fa77e883810de061319920fb7c9f71927017803407720`.
The previously synthesized copy changed the word `sync` to
`coral_private_sync` in three comments. All include files match the corresponding
Bazel ZIP members byte for byte. No additional SRAM transformation was present:
`SYNTHESIS` selects the upstream generic `Sram.v` implementation. New builds keep
the original emitted file, which is functionally identical to that baseline.

The top wrapper and build Tcl/constraints derived from AWS HDK retain their
Amazon Software License notices; the license is included at
`../cl_coralnpu/LICENSE.Amazon.txt`. Upstream generated Coral RTL is generated at
build time and retains its upstream notices. The added Python tools use the
repository's license.

This source reconstruction and report validation do not establish a reproduced
implementation or physical FPGA execution. The retained candidate has unresolved
critical warnings, DRC warnings, and shell timing exceptions. The build gates
preserve their evidence and reject deployment packaging until those issues are
resolved or a separately reviewed exact baseline is implemented. No generic rule
waivers or previously approved warning dispositions are included.


## Generated RTL identity and preserved reference inputs

Fresh generation verifies all five SCM CSR words against the actual checkout
commit. It compares the existing reference hashes after substituting only those
verified words in memory. The original generated bytes and raw hashes remain the
synthesis inputs and provenance; PR-head identity is recorded separately from a
GitHub merge checkout.

For an unchanged core/generator tree, a manual build can accept the preserved
reference emission with `--cached-rtl` and a separately reviewed
`--cached-rtl-manifest-sha256`. Intake requires the exact pinned top, all 230
includes, archive and parameter-header hashes, original emitter stamp, and a
clean checkout. Every tracked source/configuration file outside `fpga/` and
`.github/` must match the emitter revision. The cache directory and output must
be outside the source checkout; use `PYTHONDONTWRITEBYTECODE=1` for preliminary
Python checks so ignored bytecode does not dirty the source.

Cached mode records the historical generator version and that Bazel was not
executed. Both host-bridge and DDR protocol simulations still run, with the
required installed simulators. Vivado, HDK, IP, license, calibration, resource,
timing, DRC, CDC, bus-skew and packaging checks remain mandatory. Cached intake
is not evidence of a new generation, routed checkpoint or physical execution.

DDR qualification also requires exactly one expected calibration BRAM with a
well-formed nonzero `INIT_2C`, checked after synthesis and again in the reopened
checkpoint. AWS-prefixed critical warnings are included in the existing
unreviewed-warning rejection. No warning disposition is added by these checks.
